# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct. By participating, you are expected to uphold it.

To report unacceptable behavior, use [GitHub's private vulnerability reporting](https://github.com/tc3oliver/laya-apple/security/advisories/new)
on this repository, or contact the maintainer directly through GitHub.
